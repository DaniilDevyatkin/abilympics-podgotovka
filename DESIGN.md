# DESIGN.md — сайт «Абилимпикс Башкортостан»

Две страницы без сборки: `index.html` (главная) и `kompetentsii-2026.html` (перечень компетенций).
Общая база — `assets/base.css`. Внешние зависимости: Google Fonts (Jost) и фото с Wikimedia Commons.

## Источник стиля — официальный брендбук

`download.pdf` — «ФИРСТИЛЬ, 13.03.2026», 20 страниц (лежит в `/home/fun/inbox/`).
Из него взято всё: палитра, знак, шрифт, девиз.

### Цвета: синий брендбука + зелёный флага

| Токен | Значение | Пантон | Роль |
|---|---|---|---|
| `--blue` | `#0540F2` | PANTONE 286 PC (брендбук) | весь текст, линии, заливка блоков |
| `--white` | `#FFFFFF` | C0 M0 Y0 K0 | фон, текст на синем |
| `--flag-green` | `#007000` | PANTONE 356 C — нижняя полоса флага РБ | только слово «Башкортостан» |

По просьбе владельца зелёный добавлен как цвет региона: им набрано слово «БАШКОРТОСТАН» в заголовке
шапки и подпись «БАШКОРТОСТАН 2026» в логотипе на обеих страницах. Больше нигде зелёный не
используется; контраст на белом 6.3:1 (норма для мелкого текста — 4.5:1).
Остальная иерархия по-прежнему строится размером, весом и инверсией, а не оттенками.
Фото — в естественном цвете, без фильтров и цветных наложений (по просьбе владельца; раньше был
синий дуотон). Кадры подрезаются `object-fit:cover`, при наведении только лёгкий зум.
Источники фото: только официальные материалы сайта движения `abilympicsbash.ru` (файлы локально
в `assets/photos/`, внешних ссылок на изображения нет).
Контраст пары 7.4:1 — выше AA и AAA для основного текста; проверено расчётом по всем текстовым узлам.

В брендбуке есть ещё служебные голубой `#4B83F2`, светло-голубой `#C9D7F2`, красный `#E83845`,
зелёный `#009F7A` — на сайте сознательно не используются (требование владельца: два цвета).

### Знак

`brand/mark.svg` — геометрическая «А» из брендбука (`01_basics/01_logo/02`), снята из PDF как
вектор (`brand/extract_logo.py`), не нарисована заново. Сверка с рабром из PDF: IoU 0.97,
соотношение сторон 0.832 против 0.834 у оригинала. В шапке — знаком + вертикальная линейка +
«АБИЛИМПИКС / БАШКОРТОСТАН 2026» (горизонтальный локап брендбука).
`brand/lockup.svg` — полный горизонтальный локап для печати и партнёрских материалов.

### Шрифт

Jost 400/500/600/700 — свободный геометрический гротеск, аналог Futura из брендбука; тот же
шрифт использует официальный сайт чемпионата (там Futura PT + Jost). Фолбэк —
`"Futura","Futura PT","Century Gothic"`. Вторая строка манифеста подгоняется по ширине JS-ом,
чтобы слово «ПРОФЕССИОНАЛОВ» не обрезалось.

### Девиз

«КАЖДАЯ ПОБЕДА НАЧИНАЕТСЯ С МЕЧТЫ!» (брендбук, стр. 9) — надпись над манифестом.

## Главная (`index.html`)

- Шапка 76 px sticky, белая, нижняя граница 2 px синим. Логотип, название, навигация
  «Главная» / «Компетенции 2026» (`aria-current` у активного пункта).
- Блок команды перед альбомом: текст слева (`h1` «Команда / Республики / Башкортостан»,
  одна строка пояснения, ссылка «Сайт движения»), справа фото сборной региона на сцене
  национального чемпионата. Кадр 4:3, на ≤899 px фото уходит наверх, текст под ним.
  Заголовок подгоняется по ширине JS-ом (как манифест): слово «БАШКОРТОСТАН» не залезает на фото
  ни на 320, ни на 1440 px.
- Альбом: горизонтальная лента 7 карточек. Ширина `clamp(230px,27vw,390px)`, каждая третья
  шире (`clamp(260px,30.5vw,450px)`), чётные сдвинуты вниз (`clamp(0px,2.4vw,34px)`).
  Кадр 4:3, у широких 16:10. На карточке только номер кадра и название компетенции.
  Стрелки 40×40 на десктопе и 44×44 на мобиле (тап-зона).
- Счётчик `01 / 07`, две стрелки 40×40, шкала прогресса на 2 px-линиях.
- Манифест — синяя плашка во всю ширину: девиз, затем «ГОТОВИМ / ПРОФЕССИОНАЛОВ»
  (`clamp(30px,10.6vw,190px)`, `line-height:.86`). После заголовка в блоке ничего нет.
- Подвал: © 2026, «Республика Башкортостан, г. Салават».

## Компетенции 2026 (`kompetentsii-2026.html`)

- Заголовок, справка, три числа: 308 компетенций / 25 разделов / 2026.
- Липкая панель: поиск (нормализует регистр и `ё`→`е`, debounce 90 мс) и алфавит-чипсы
  с количеством по разделу; пустые разделы гаснут, есть пустое состояние.
- 308 ссылок в 25 разделах, каждая ведёт на официальную страницу компетенции
  (`abilympics-russia.ru/competencies/Komp2026/...`), `target="_blank" rel="noopener"`.
- Список: 1 / 2 / 3 колонки по ширине, буква раздела закреплена при скролле (≥720 px).
- Данные выгружены из официальной страницы чемпионата скриптом (`competencies.json`),
  сверено: 308 позиций, дублей 0.

## Страницы компетенций (kompetentsii/<slug>.html)

308 страниц, по одной на компетенцию. Генерируются `scripts/build_pages.py` из:
`competencies.json` (названия), `assets/docs/<slug>/meta.json` (что вырезано из официального КЗ),
`solutions/<slug>.json` (написанные решения).

На странице три блока — Школьник / Студент / Специалист. В каждом:
файл конкурсного задания (PDF, вырезанные из официального КЗ страницы этой категории)
и `<details>` «Пошаговое решение».

### Формат решения (структура «задание → задача → действие → шаг»)

Решение — не список советов, а декомпозиция:
задание → задачи (4–5) → действия (13–16) → шаги (45–59 на категорию).
У каждого шага пять полей: **что делаем**, **зачем**, **как проверить**,
**типичная ошибка**, **что видит эксперт**. Плюс таблица распределения баллов и «красные флаги».

Данные лежат в `solutions/<slug>.json`, рендерит `scripts/sol_render.py`, CSS-классы `.s-*`
в шаблоне страницы. Схемы — `scripts/make_schemes.py` (SVG в `assets/img/`): таймлайн конкурса,
маркировка досок, слои бенто-торта, формовка зраз, схема тарелки, температурная шкала,
толщина нарезки. Картинки ставятся и на задачу, и на отдельный шаг.

Для «Поварского дела» готовы все три категории: 59 шагов (школьники), 45 (студенты), 49 (специалисты).

Вырезание заданий делает `scripts/extract_kz.py`: находит разделы «2.1.x / 2.3.x / 2.4.x
Категория участников «…»», собирает относящиеся к категории страницы и склеивает в отдельный PDF
с титулом-выдержкой (шрифт DejaVu — встроенный helv не умеет кириллицу).
Если в документе категории не разделены — отдаётся всё КЗ целиком с пометкой.

Итог разбора 308 официальных КЗ: у 607 категорий (из 924) есть собственные страницы,
у 317 — задание общее, категории различаются только таблицей модулей.

## Интерактив

- Перетаскивание pointer-событиями с инерцией (затухание 0.94), `scroll-snap` отключается на drag.
- Колесо/тач по горизонтали, `overscroll-behavior-x:contain`.
- Стрелки, `←`/`→`, `Home`/`End`; счётчик считается по позиции карточки, а не по индексу.
- `prefers-reduced-motion` выключает переходы и smooth-scroll.

## Доступность

- Один `h1` на страницу (на главной — скрытый заголовок, манифест `h2`), разделы `h2`.
- Skip-ссылка, `aria-current`, `aria-controls`, live-регион «Кадр N из 7», фокус 3 px.
- Поиск: видимый label для скринридера, `role="status"` со счётчиком результатов.
- Контраст проверен скриптом по всем текстовым узлам обеих страниц: нарушений нет.
- Изображения: `alt` у всех 7 фото, `width`/`height` заданы, ленивая загрузка кроме первого.

  все 7 фото грузятся (`naturalWidth` 1280).

  `scrollWidth` каждого слова и зазору между колонками).
